# JJ 과제 확인

전주대학교 사이버캠퍼스의 과제와 제출 상태를 확인하고, 개인 과제를
추가로 관리할 수 있는 **Streamlit 기반 과제 대시보드**입니다.

## 주요 기능

-   **사이버캠퍼스 로그인**: 학번과 비밀번호로 로그인하고 Moodle
    웹서비스 API 토큰을 발급받습니다.
-   **과제 목록 조회**: 수강 강의와 각 강의의 과제 정보를 가져옵니다.
-   **제출 상태 확인**: 과제별 제출 상태를 조회해 제출 또는 미제출로
    표시합니다. 상태를 확인할 수 없는 경우에는 `확인불가`로 표시합니다.
-   **마감 임박도 표시**: 남은 시간에 따라 과제의 긴급도를 구분합니다.
-   **마감 지난 과제 제외**: 현재 시각을 기준으로 마감 시간이 지난
    과제는 목록에서 제외합니다.
-   **마감일순 정렬**: 마감일이 가까운 과제부터 표시합니다.
-   **개인 과제 추가 및 관리**: 사이버캠퍼스에 등록되지 않은 과제도 직접
    추가하고, 완료 상태 변경 및 삭제를 할 수 있습니다.
-   **검색 조건 필터링**: 강의, 긴급도, 미제출 여부를 기준으로 목록을
    필터링합니다.
-   **요약 지표 제공**: 수강 강의 수, 진행 과제 수, 미제출 수, 24시간
    이내 및 7일 이내 마감 과제 수를 보여줍니다.

## 실행 환경 및 사용 라이브러리

-   Python 3.x
-   Streamlit
-   pandas
-   requests

표준 라이브러리도 사용합니다: `json`, `uuid`, `datetime`, `pathlib`,
`zoneinfo`.

## 설치 방법

프로젝트 파일이 있는 폴더에서 터미널을 열고 필요한 라이브러리를
설치합니다.

``` bash
pip install streamlit pandas requests
```

## 실행 방법

파이썬 코드 파일을 예를 들어 `app.py`라는 이름으로 저장한 뒤, 해당
파일이 있는 폴더에서 다음 명령어를 실행합니다.

``` bash
streamlit run app.py
```

실행 후 터미널에 표시되는 로컬 주소(일반적으로
`http://localhost:8501`)를 브라우저에서 엽니다.

## 사용 방법

1.  앱을 실행하고 왼쪽 사이드바의 로그인 영역에 사이버캠퍼스 학번과
    비밀번호를 입력합니다.
2.  **로그인** 버튼을 누릅니다.
3.  로그인에 성공하면 사이버캠퍼스에서 과제 목록을 불러옵니다.
4.  필요하면 **과제 직접 추가하기** 영역에서 개인 과제를 등록합니다.
5.  직접 추가한 과제는 관리 영역에서 완료 체크를 하거나 삭제할 수
    있습니다.
6.  과제 목록에서 강의·긴급도 필터 또는 **미제출만 보기**를 사용해
    원하는 과제만 확인합니다.
7.  **새로고침** 버튼을 누르면 캐시를 비우고 데이터를 다시 조회합니다.
8.  **로그아웃** 버튼을 누르면 앱의 로그인 토큰 상태를 초기화합니다.

## 과제 표시 기준

### 긴급도

  남은 시간                     표시
  ----------------------------- ----------------
  마감 시간이 지남              ⚫ 마감
  24시간 이하                   🔴 24시간 이내
  24시간 초과 \~ 72시간 이하    🟠 3일 이내
  72시간 초과 \~ 168시간 이하   🟡 7일 이내
  168시간 초과                  🟢 여유

마감 시간이 지난 과제는 데이터프레임에 포함하지 않습니다.

### 제출 상태

  API 상태                      화면 표시
  ----------------------------- -------------
  `submitted`                   ✅ 제출
  그 외 기본 상태(`new`)        ❌ 미제출
  제출 상태 조회 중 오류 발생   ❔ 확인불가

직접 추가한 과제는 등록 시 미완료 상태이며, 관리 영역의 체크박스로 완료
여부를 변경할 수 있습니다.

## 데이터 저장 및 캐시

-   직접 추가한 과제는 코드 파일과 같은 폴더의 `my_assignments.json`
    파일에 저장됩니다.
-   `my_assignments.json`은 직접 추가한 과제의 강의명, 과제명, 마감일,
    링크, 메모, 완료 여부 등을 보관합니다.
-   사이버캠퍼스 과제 목록과 제출 상태 조회 함수에는 Streamlit의
    `st.cache_data(ttl=300)` 캐시가 적용되어 있습니다. 캐시 유효 시간은
    300초(5분)입니다.
-   사이드바의 새로고침 버튼은 캐시를 비운 뒤 화면을 다시 실행합니다.
-   로그인 토큰은 `st.session_state`에 저장됩니다. 현재 코드에는 토큰을
    파일에 영구 저장하는 기능은 없습니다.

## 코드 구성

  -------------------------------------------------------------------------------
  함수 / 영역                                 역할
  ------------------------------------------- -----------------------------------
  `load_manual()`                             `my_assignments.json`에서 직접
                                              추가한 과제를 불러옵니다.

  `save_manual(items)`                        직접 추가한 과제 목록을 JSON 파일로
                                              저장합니다.

  `login(username, password)`                 사이버캠퍼스에 로그인 요청을 보내
                                              API 토큰을 발급받습니다.

  `call_api(token, wsfunction, **params)`     Moodle 웹서비스 API를 호출하고 응답
                                              및 API 오류를 확인합니다.

  `get_assignments(token)`                    수강 강의와 과제 목록을 조회합니다.

  `get_submission_status(token, assign_id)`   과제의 제출 상태를 조회합니다.

  `format_remaining(td)`                      남은 시간을 일·시간·분 형식으로
                                              변환합니다.

  `urgency(hours_left)`                       남은 시간에 따라 긴급도 라벨을
                                              반환합니다.

  `build_dataframe(courses, token, manual)`   개인 과제와 사이버캠퍼스 과제를
                                              합치고, 마감 지난 과제를 제외한 뒤
                                              마감일순으로 정렬합니다.

  Streamlit UI 영역                           로그인, 과제 추가·관리, 요약 지표,
                                              필터 및 과제 표를 화면에
                                              표시합니다.
  -------------------------------------------------------------------------------

## API 및 시간대 설정

코드에서 사용하는 사이버캠퍼스 주소와 API 경로는 다음과 같습니다.

-   기본 주소: `https://cyber.jj.ac.kr`
-   토큰 발급: `/login/token.php`
-   웹서비스 API: `/webservice/rest/server.php`
-   토큰 발급 서비스: `moodle_mobile_app`
-   시간대: `Asia/Seoul` (한국 표준시)

## 참고 및 주의 사항

-   이 프로그램은 사이버캠퍼스의 로그인 및 Moodle 웹서비스 API 응답에
    의존합니다. 사이트의 API 정책이나 응답 형식이 바뀌면 일부 기능이
    작동하지 않을 수 있습니다.
-   학번과 비밀번호는 로그인 요청에 사용됩니다. 코드를 공개 저장소에
    올릴 때 계정 정보를 코드에 직접 적거나 로그에 노출하지 않도록
    주의하세요.
-   `my_assignments.json`에는 사용자가 직접 입력한 과제 정보가
    저장됩니다. 이 파일을 삭제하면 직접 등록한 과제 데이터도 사라집니다.
-   제출 상태 조회에 실패하면 프로그램은 오류를 중단하지 않고 해당
    과제를 `확인불가`로 표시하도록 작성되어 있습니다.
-   현재 코드는 로그인 토큰의 영구 저장이나 자동 로그인 기능을 구현하지
    않습니다.
